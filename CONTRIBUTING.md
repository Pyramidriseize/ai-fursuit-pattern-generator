# Contributing

Thanks for the interest. Furge is a small tool with a narrow scope, so
before opening a PR please open an issue first and describe what you want to
change.

## Ground rules

- One PR per change, small diffs.
- Bugs first, features second.
- No telemetry, no accounts, no cloud: if a change needs a server, it will be
  declined.
- Everything stays local to the user's machine.

## Development

```
git clone https://github.com/Pyramidriseize/ai-fursuit-pattern-generator.git
cd furge
```

Follow the build notes in the README. Test before you push.
